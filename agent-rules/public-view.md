# 공개 조회 경계

- `publicview`는 JPA 엔티티·리포지터리·애플리케이션 서비스를 재사용하지 않는다. 전용 SQL 쿼리로 허용된 컬럼만 조회한다.
- 공개 URL에는 내부 record ID가 아니라 회원 slug만 노출한다.
- 비공개, 없는, 탈퇴한 서재는 모두 같은 404 응답을 반환한다.
- 공개 요청은 외부 제공자를 동기로 호출하지 않는다. 캐시 데이터를 렌더링하고 필요할 때 갱신 작업을 큐에 넣는다.
- 공개 페이지 코드를 바꿀 때 `PublicViewArchitectureTest`가 검증하는 경계를 보존한다.
