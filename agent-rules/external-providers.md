# 외부 제공자와 백그라운드 작업

- 제공자 호출에는 유한한 일일 예산이 들며 사용자별 한도도 적용될 수 있다. 캐시 우선 동작과 클라이언트 단위의 호출 집계를 유지한다.
- 공개 트래픽은 갱신을 큐에 넣을 수 있지만, 실제 갱신은 백그라운드 작업자가 수행한다.
- 제공자가 주지 않은 상태나 가격을 부풀리지 않는다. 값이 없으면 알 수 없는 상태로 남긴다.
- 제공자 실패 응답이나 예외 메시지에 API 키 또는 키가 포함된 요청 URL을 노출하지 않는다.
- 설정된 타임아웃, 쿨다운, 백그라운드 상한을 따른다. 제공자 전용 동작은 해당 클라이언트 패키지에 둔다.
