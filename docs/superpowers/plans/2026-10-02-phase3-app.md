# Phase 3 — Flutter 앱과 공유 흐름 (W8~W11) 구현 계획 · 예정

> 이 문서는 아직 시작하지 않은 구현 계획이다. 특정 에이전트 프레임워크를 요구하지 않으며, 실제 작업에는 저장소 루트의 `AGENTS.md`와 `agent-rules/`를 따른다. 체크박스는 작업을 시작할 때 갱신한다.

**Goal:** 서점에 서서 폰으로 책을 찍으면 동네 도서관에 있는지와 어디서 살 수 있는지가 보이고, 집에 와서 그 서재 링크를 공유할 수 있는 iOS 앱을 로컬에서 완성한다 (설계 문서 4장 완료 기준).

**Architecture:** 서버에 두 가지를 더한다 — 공유 흐름용 서재 API(일괄 공개 전환, 서재 스위치)와 Google Play 전자책 가격(같은 책 확인 + 24시간 캐시). 앱은 같은 저장소의 `app/`에 Flutter로 만든다. 상태는 Riverpod, 화면 이동은 go_router, HTTP는 dio(인증 인터셉터가 refresh를 한 번에 하나만 보낸다). 화면은 서버 API의 모양만 알고 제공자 이름은 모른다. 책 상세는 칸마다 따로 받아 먼저 온 칸부터 그린다.

**Tech Stack:** 서버는 Phase 2 그대로(Spring Boot 4.1.1, Java 21, PostgreSQL 16, WireMock). 앱은 Flutter stable(Task 0에서 설치·기록), Dart 3, `flutter_riverpod` 3.x, `go_router`, `dio` 5.x, `flutter_secure_storage`(iOS Keychain), `mobile_scanner`(EAN-13), `share_plus`, `url_launcher`

**Spec:** `docs/superpowers/specs/2026-09-27-book-shelf-design.md` — 2-1(읽을 수단 한 화면, 같은 책 확인), 4(MVP), 6-4(디바운스), 6-5(캐시), 7-3·7-4·7-5(visibility, 공유 흐름, 비공개 전환 안내), 9장 W8~W11. 제공자 실측: `docs/notes/providers.md`
**이전 계획:** `docs/superpowers/plans/2026-09-30-phase2-auth-library.md` (완료, main 병합)

**이 계획의 범위와 사용자 결정 (2026-10-02):**
1. **로컬 우선.** Apple Developer 멤버십은 보류한다. 앱의 로그인은 **로컬 전용 개발 로그인**(`POST /api/auth/dev`, Phase 2 이후 추가)만 쓴다. Apple 로그인 버튼·TestFlight·App Store는 범위 밖
2. **상태 관리는 Riverpod.** 칸별 점진 로딩을 `AsyncValue`(로딩/데이터/오류)로 그리고, 테스트에서 가짜 API로 갈아 끼운다
3. **실행 대상은 iPhone 실기기 + iOS 시뮬레이터.** 바코드 스캔은 카메라가 필요해 실기기에서 확인한다(무료 Apple ID 서명, 7일마다 재설치). Android 설정은 `flutter create`가 만든 그대로 두고 따로 확인하지 않는다
4. **앱 코드는 같은 저장소의 `app/`.** API를 바꿀 때 한 커밋에 양쪽이 들어간다

**넘기는 것:** Apple 로그인 UI와 Apple 탈퇴 경로의 앱 쪽(멤버십 가입 후), 강제 업데이트 스위치(Phase 4), 공개 경계 테스트 보강(Phase 4), TestFlight, **검색 목록의 "내 도서관에 있음"**(정보나루 일 500 — 설계 9장 버리는 순서 2와 Phase 2의 결정대로 상세에서만 보여준다)

## Global Constraints

- 커밋·푸시·검증 규칙은 `agent-rules/workflow.md`를 따른다.
- **Flyway의 기존 V 파일(V1~V5)은 고치지 않는다.** 이 계획의 스키마는 `V6__ebook_offer.sql` 하나
- **API 응답에서 필드를 삭제하지 않는다(추가만).** 앱은 롤백이 안 되고 옛 버전이 남는다 (설계 8장). 이 계획의 서버 변경은 새 엔드포인트와 새 필드뿐이다
- **공개 페이지는 어떤 제공자도 동기로 부르지 않는다.** 전자책 가격은 앱 API에만 둔다 (설계 2-1)
- **Google Books:** 키는 기본값 없이 환경변수(`GOOGLE_BOOKS_KEY`, `.env`에 이미 있다). 키는 URL 쿼리에 실리므로 **HTTP 예외의 메시지·cause를 밖으로 내보내지 않는다**(정보나루와 같다). 결과 옆에 **"powered by Google"**, 각 결과에 **Google Books 페이지 링크** (브랜딩 규칙). 앱 사용에 요금을 받지 않는다
- **같은 책 확인 여섯 조건을 모두 통과하고 후보가 정확히 하나일 때만 가격을 보여준다.** 가격은 `KRW`이고 0보다 클 때만. 언어를 모르는 ISBN(978-89·979-11·978-0·978-1 밖)은 **Google을 부르지 않는다** (설계 2-1)
- `EbookOffer` 캐시는 **24시간, "같은 책 없음"도 캐시** (설계 6-5). 제공자 장애는 캐시하지 않는다
- Google Books 한도는 공개되지 않았다(콘솔 할당량, Task 0에서 확인). 우리 상한은 **900/일, 백그라운드 300**, 초기화는 **America/Los_Angeles 자정**(가정) — Task 0에서 확인한 값의 90%·30%로 바꾼다
- **일괄 공개 전환은 읽음(`DONE`) 기록만 바꾼다.** 읽고 싶다·읽는 중 기록과 회원의 기본 visibility는 바꾸지 않는다. 서재 스위치는 켠다 (설계 7-4)
- **서재를 닫을 때 "검색 결과에서 사라지는 데 며칠 걸릴 수 있다"고 알린다** (설계 7-5)
- 앱 검색: **입력이 400ms 멈춘 뒤, 2글자 이상일 때만** 호출. 목록은 **10권씩** (설계 6-4, 2-1)
- 앱 표시 규칙(설계 2-1): 상태가 있는 칸에만 기준 시각("N시간 전 기준", 빌리기는 "전날 기준"), 링크는 "검색하기"이지 "판다"가 아니다, 제공자가 죽으면 그 칸만 "확인 불가"이고 링크는 남는다, 판매 상태가 비면 "판매 정보 없음"(절판이라 하지 않는다), 가격이 없으면 숫자를 쓰지 않는다
- **앱은 refresh 요청을 한 번에 하나만 보낸다.** 서버는 이미 쓴 refresh가 다시 오면 그 회원의 모든 refresh를 폐기한다 (Phase 2 Task 3)
- refresh 토큰은 **iOS Keychain**(`flutter_secure_storage`)에만 둔다. 로그·화면에 토큰을 찍지 않는다
- **Riverpod 3의 자동 재시도를 끈다**(`ProviderScope(retry: (_, __) => null)`). 켜 두면 실패한 칸이 스스로 다시 불러 사용자 상한·제공자 예산을 태운다
- 앱 패키지 버전은 `flutter pub add`가 고른 최신 호환 버전을 쓰고 `pubspec.lock`을 커밋한다. **이 계획의 코드는 `flutter_riverpod` 3.x, `go_router` 14 이상, `dio` 5.x, `mobile_scanner` 6~7, `share_plus` 11 이상의 API를 기준으로 쓴다** — 다른 메이저가 깔리면 그 Task에 Ruling을 남기고 맞춘다
- Riverpod 3은 덜 쓰는 타입 일부를 `package:flutter_riverpod/misc.dart`로 옮겼다. `Override`가 없다는 컴파일 오류가 나면 그 파일(`auth_controller.dart`, `test/support/harness.dart`)에 `import 'package:flutter_riverpod/misc.dart';`를 더한다
- 시간은 서버가 준 `Instant`(ISO-8601 UTC)를 앱이 `DateTime.parse(...).toLocal()`로 읽는다. 날짜(`startedAt` 등)는 `yyyy-MM-dd` 문자열 그대로 주고받는다

## Review Focus

설계 문서가 말하지 않았지만 실제로 폰을 든 사람이 가장 먼저 부딪힐 다섯 가지다. 각 줄의 테스트는 담당 Task에 들어 있다.

1. **access 토큰이 만료된 순간 화면이 요청 여러 개를 동시에 보낸다** (책 상세는 칸 네 개를 한꺼번에 부른다) — refresh는 **한 번만** 나가고 나머지는 새 토큰으로 다시 보낸다. refresh가 실패하면 로그아웃 화면으로 간다 → Task 4
2. **책이 아닌 바코드를 찍거나, 카메라가 같은 바코드를 1초에 열 번 읽는다** — 책이 아니면 서버를 부르지 않고 안내만 한다. 같은 책 상세는 **한 번만** 열린다 → Task 7
3. **한 칸의 제공자가 죽었다** (정보나루 장애, Google 느림) — 그 칸만 "확인 불가"이고 책 정보·새 책·링크 칸은 그대로 그려진다 → Task 8
4. **한줄평에 이모지·결합 문자를 쓴다** — Flutter의 글자 수(그래핌)와 서버의 200자(코드포인트)가 다르다. 앱은 서버 기준으로 세고, 넘으면 저장 전에 막는다 → Task 6
5. **제공자에 없는 책(독립출판·해외서)을 찍는다** — "책 정보를 찾지 못했어요"와 함께 **ISBN만으로 기록할 수 있다**. 기록은 서재에 회색 표지로 남는다 (설계 5장) → Task 8

### Task 1: 서재 공유 API — 공유를 누르는 순간 공개를 묻는다

설계 문서 7-4. 기본 비공개는 그대로 두고, 공개를 "설정에서 켜는 것"이 아니라 "공유를 누르는 순간의 흐름"으로 만든다. 앱(Task 11)이 쓰는 서버 쪽 세 가지:
- `GET /api/me/shelf` — 서재가 열렸는지, 공유할 주소, 읽은 책 수(대화상자의 "읽은 책 32권 모두 공개")
- `POST /api/me/shelf/publish {mode}` — 읽음 기록을 `PUBLIC` 또는 `RATING_ONLY`로 바꾸고 서재를 연다. **읽고 싶다·읽는 중 기록, 회원의 기본 visibility는 바꾸지 않는다**
- `POST /api/me/shelf/close` — 서재를 닫는다. 기록의 visibility는 그대로 둔다(다시 열면 그대로 보인다)

그리고 Phase 2에서 넘긴 **기본 공개 범위 변경**을 `PATCH /api/me`에 더한다(필드 추가 — 옛 앱은 보내지 않으니 그대로 동작한다).

**Files:**
- Modify: `src/main/java/com/bookshelf/member/domain/Member.java` (`changeDefaultVisibility`)
- Modify: `src/main/java/com/bookshelf/member/application/MemberService.java` (`update`에 `defaultVisibility`)
- Modify: `src/main/java/com/bookshelf/member/presentation/MeController.java` (`UpdateRequest`에 `defaultVisibility`)
- Create: `src/main/java/com/bookshelf/member/application/ShelfService.java`, `ShelfView.java`
- Create: `src/main/java/com/bookshelf/member/presentation/ShelfController.java`
- Test: `src/test/java/com/bookshelf/member/ShelfApiTest.java`

**Interfaces:**
- Consumes: `MemberService#active(long) -> Member`, `ActiveMemberLock#lock(long)`(Phase 2 리뷰 수정), `BookshelfProperties#siteUrl()`, `Member#openShelf()`, `#closeShelf()`, `Visibility`
- Produces:
  - `record ShelfView(boolean shelfPublic, String url, int doneCount, int visibleCount)` — `url`은 `{site-url}/u/{slug}`, `visibleCount`는 `PUBLIC`·`RATING_ONLY` 기록 수(서재가 열리면 보이는 수)
  - `ShelfService#view(long) -> ShelfView`, `#publish(long, Visibility mode) -> ShelfView`(mode는 `PUBLIC`·`RATING_ONLY`만, 아니면 `DomainException`), `#close(long) -> ShelfView`
  - `Member#changeDefaultVisibility(Visibility)` — null이면 `DomainException`
  - `MemberService#update(long memberId, String slug, String displayName, Visibility defaultVisibility) -> MeView` (null은 그대로 둔다)
  - HTTP: `GET /api/me/shelf`, `POST /api/me/shelf/publish {"mode":"PUBLIC"|"RATING_ONLY"}`, `POST /api/me/shelf/close`, `PATCH /api/me {..., "defaultVisibility"}`

  ```java
  package com.bookshelf.member.application;

  import com.bookshelf.common.BookshelfProperties;
  import com.bookshelf.common.DomainException;
  import com.bookshelf.member.domain.Member;
  import com.bookshelf.record.domain.Visibility;
  import org.springframework.jdbc.core.simple.JdbcClient;
  import org.springframework.stereotype.Service;
  import org.springframework.transaction.annotation.Transactional;

  import java.sql.Timestamp;
  import java.time.Clock;

  /**
   * 공유 흐름 (설계 문서 7-4). 일괄 전환은 읽음(DONE) 기록만 바꾼다 — 읽고 싶다·읽는 중과
   * 회원의 기본 visibility(앞으로 만들 기록)는 그대로 비공개다.
   */
  @Service
  public class ShelfService {

      private final MemberService members;
      private final ActiveMemberLock memberLock;
      private final JdbcClient jdbc;
      private final BookshelfProperties props;
      private final Clock clock;

      public ShelfService(MemberService members, ActiveMemberLock memberLock, JdbcClient jdbc,
                          BookshelfProperties props, Clock clock) {
          this.members = members;
          this.memberLock = memberLock;
          this.jdbc = jdbc;
          this.props = props;
          this.clock = clock;
      }

      @Transactional(readOnly = true)
      public ShelfView view(long memberId) {
          return view(members.active(memberId));
      }

      @Transactional
      public ShelfView publish(long memberId, Visibility mode) {
          if (mode != Visibility.PUBLIC && mode != Visibility.RATING_ONLY) {
              throw new DomainException("공개 방식은 PUBLIC 또는 RATING_ONLY다: " + mode);
          }
          memberLock.lock(memberId);   // 탈퇴와 겹치면 멈춘다
          Member m = members.active(memberId);
          jdbc.sql("""
                  UPDATE reading_record SET visibility = :v, updated_at = :now
                  WHERE member_id = :m AND status = 'DONE'
                  """)
                  .param("v", mode.name())
                  .param("now", Timestamp.from(clock.instant()))
                  .param("m", memberId)
                  .update();
          m.openShelf();
          return view(m);
      }

      /** 기록의 visibility는 그대로 둔다 — 다시 열면 닫기 전처럼 보인다 */
      @Transactional
      public ShelfView close(long memberId) {
          Member m = members.active(memberId);
          m.closeShelf();
          return view(m);
      }

      private ShelfView view(Member m) {
          record Counts(int done, int visible) {
          }
          Counts c = jdbc.sql("""
                  SELECT count(*) FILTER (WHERE status = 'DONE') AS done,
                         count(*) FILTER (WHERE visibility IN ('PUBLIC', 'RATING_ONLY')) AS visible
                  FROM reading_record WHERE member_id = :m
                  """)
                  .param("m", m.getId())
                  .query((rs, n) -> new Counts(rs.getInt("done"), rs.getInt("visible")))
                  .single();
          return new ShelfView(m.isShelfPublic(), props.siteUrl() + "/u/" + m.getSlug(), c.done(), c.visible());
      }
  }
  ```

  ```java
  package com.bookshelf.ebook;

  import java.text.Normalizer;
  import java.util.LinkedHashMap;
  import java.util.List;
  import java.util.Locale;
  import java.util.Map;
  import java.util.regex.Matcher;
  import java.util.regex.Pattern;

  /**
   * 같은 책 확인 (설계 문서 2-1). 여섯 조건을 모두 통과하고 후보가 정확히 하나일 때만 Matched다.
   * 애매하면 NoMatch — 틀린 숫자보다 숫자 없음이 낫다.
   */
  public final class EbookMatcher {

      public sealed interface Result permits Matched, NoMatch {
      }

      public record Matched(EbookCandidate offer) implements Result {
      }

      /** reason은 로그용 */
      public record NoMatch(String reason) implements Result {
      }

      private static final Pattern PARENS = Pattern.compile("[(\\[]([^)\\]]*)[)\\]]");
      private static final Pattern VOLUME = Pattern.compile("(\\d+)권");
      private static final Pattern PART = Pattern.compile("(\\d+)부");
      private static final Pattern EPISODE = Pattern.compile("(\\d+)편");
      private static final Pattern TRAILING_NUMBER = Pattern.compile("(\\d+)\\s*$");
      private static final Pattern TRAILING_SANGHA = Pattern.compile("\\s(상|중|하)\\s*$");
      private static final Pattern NOT_LETTER_OR_DIGIT = Pattern.compile("[^\\p{L}\\p{N}]");

      private EbookMatcher() {
      }

      public static Result match(String bookTitle, String bookAuthors, String language, List<EbookCandidate> candidates) {
          String title = normalizeTitle(bookTitle);
          String author = normalizeAuthor(firstAuthor(bookAuthors));
          if (title.isEmpty() || author.isEmpty() || language == null) {
              return new NoMatch("우리 책의 제목·저자·언어가 없다");
          }
          Volume volume = Volume.of(bookTitle);

          Map<String, EbookCandidate> passed = new LinkedHashMap<>();
          for (EbookCandidate c : candidates) {
              if (!c.ebook()) {
                  continue;                                              // 종이책 항목은 후보가 아니다
              }
              if (!language.equals(c.language())) {
                  continue;                                              // 1. 언어
              }
              if (!title.equals(normalizeTitle(c.title()))) {
                  continue;                                              // 2. 제목
              }
              if (!volume.equals(Volume.of(c.title()))) {
                  continue;                                              // 3. 권 표시
              }
              if (c.authors() == null || c.authors().stream().map(EbookMatcher::normalizeAuthor).noneMatch(author::equals)) {
                  continue;                                              // 4. 저자
              }
              passed.putIfAbsent(c.ebookIsbn13() != null ? c.ebookIsbn13() : c.volumeId(), c);
          }
          if (passed.size() != 1) {
              return new NoMatch("같은 책 후보 " + passed.size() + "개");     // 5. 정확히 하나
          }
          EbookCandidate only = passed.values().iterator().next();
          if (!"KRW".equals(only.currency()) || only.retailPrice() == null || only.retailPrice() <= 0) {
              return new NoMatch("원화 가격 없음");                          // 6. KRW, 0원은 무료로 단정하지 않는다
          }
          return new Matched(only);
      }

      /** NFC → 소문자 → ':' 뒤 부제 제거 → 괄호와 안 내용 제거 → 권 표시 제거 → 문장부호·공백 제거 */
      static String normalizeTitle(String raw) {
          if (raw == null) {
              return "";
          }
          String t = Normalizer.normalize(raw, Normalizer.Form.NFC).toLowerCase(Locale.ROOT);
          int colon = t.indexOf(':');
          if (colon >= 0) {
              t = t.substring(0, colon);
          }
          t = PARENS.matcher(t).replaceAll(" ");
          t = VOLUME.matcher(t).replaceAll(" ");
          t = PART.matcher(t).replaceAll(" ");
          t = EPISODE.matcher(t).replaceAll(" ");
          String withoutTrailing = TRAILING_SANGHA.matcher(TRAILING_NUMBER.matcher(t.strip()).replaceAll("")).replaceAll("");
          if (!NOT_LETTER_OR_DIGIT.matcher(withoutTrailing).replaceAll("").isEmpty()) {
              t = withoutTrailing;   // 숫자뿐인 제목("1984")은 남긴다
          }
          return NOT_LETTER_OR_DIGIT.matcher(t).replaceAll("");
      }

      /** 공백 제거 → 소문자 → 끝의 "외" 제거 */
      static String normalizeAuthor(String raw) {
          if (raw == null) {
              return "";
          }
          String a = Normalizer.normalize(raw, Normalizer.Form.NFC).replaceAll("\\s", "").toLowerCase(Locale.ROOT);
          return a.endsWith("외") ? a.substring(0, a.length() - 1) : a;
      }

      private static String firstAuthor(String authors) {
          return authors == null ? null : authors.split(",")[0].strip();
      }

      /** 권(N권 → N편 → 괄호 밖 제목 끝 숫자 → 상·중·하)과 부(N부). 둘 다 같아야 같은 권이다 */
      record Volume(String volume, String part) {

          static Volume of(String raw) {
              String t = raw == null ? "" : Normalizer.normalize(raw, Normalizer.Form.NFC);
              String volume = first(VOLUME, t);
              if (volume == null) {
                  volume = first(EPISODE, t);
              }
              if (volume == null) {
                  String main = PARENS.matcher(t).replaceAll(" ").strip();
                  volume = first(TRAILING_NUMBER, main);
                  if (volume == null) {
                      volume = first(TRAILING_SANGHA, main);
                  }
              }
              if (volume == null) {
                  Matcher paren = PARENS.matcher(t);
                  while (paren.find()) {
                      String inside = paren.group(1).strip();
                      if (inside.equals("상") || inside.equals("중") || inside.equals("하")) {
                          volume = inside;
                          break;
                      }
                  }
              }
              return new Volume(volume == null ? null : stripZeros(volume), stripZeros(first(PART, t)));
          }

          private static String first(Pattern p, String s) {
              Matcher m = p.matcher(s);
              return m.find() ? m.group(1) : null;
          }

          private static String stripZeros(String n) {
              return n == null || !n.chars().allMatch(Character::isDigit) ? n : String.valueOf(Integer.parseInt(n));
          }
      }
  }
  ```

  `Volume.of`의 "괄호 밖 제목 끝 숫자"는 괄호를 지운 뒤의 끝이다: "해리 포터와 마법사의 돌 1(해리포터 20주년 개정판)" → "해리 포터와 마법사의 돌 1" → `1`. 괄호 안의 "20주년"은 보지 않는다.

  ```java
  package com.bookshelf.ebook.google;

  import com.bookshelf.ebook.EbookCandidate;
  import com.bookshelf.ebook.EbookPricing;
  import com.bookshelf.provider.CallBudget;
  import com.bookshelf.provider.CallPurpose;
  import com.bookshelf.provider.Provider;
  import com.bookshelf.provider.ProviderUnavailableException;
  import org.springframework.stereotype.Component;
  import org.springframework.web.client.RestClient;
  import org.springframework.web.client.RestClientException;
  import tools.jackson.core.JacksonException;
  import tools.jackson.databind.json.JsonMapper;

  import java.time.Clock;
  import java.time.Instant;
  import java.util.ArrayList;
  import java.util.List;

  /**
   * Google Books 호출의 유일한 입구. 순서는 다른 제공자와 같다: 쿨다운 → 예산 → HTTP → 번역.
   * 키가 URL 쿼리에 있으므로 HTTP 예외의 메시지와 cause를 밖으로 내보내지 않는다(Data4LibraryClient와 같다).
   */
  @Component
  public class GoogleBooksClient implements EbookPricing {

      private static final JsonMapper JSON = JsonMapper.builder().build();

      private final RestClient rest;
      private final CallBudget budget;
      private final GoogleBooksProperties props;
      private final Clock clock;

      private volatile Instant coolDownUntil = Instant.MIN;

      public GoogleBooksClient(RestClient googleRestClient, CallBudget budget, GoogleBooksProperties props, Clock clock) {
          this.rest = googleRestClient;
          this.budget = budget;
          this.props = props;
          this.clock = clock;
      }

      /** 종이책 ISBN으로는 전자책이 나오지 않는다(실측) — 제목+첫 저자로 찾는다. 같은 책인지는 EbookMatcher가 본다 */
      @Override
      public List<EbookCandidate> candidates(String title, String author, CallPurpose purpose) {
          if (purpose == CallPurpose.BACKGROUND && clock.instant().isBefore(coolDownUntil)) {
              throw new ProviderUnavailableException(Provider.GOOGLE_BOOKS, "쿨다운 중 (" + coolDownUntil + "까지)");
          }
          budget.acquire(props.policy(), purpose);
          String q = "intitle:" + searchTitle(title) + " inauthor:" + firstAuthor(author);
          GoogleBooksResponse r;
          try {
              byte[] body = rest.get().uri(b -> b.path("/books/v1/volumes")
                              .queryParam("q", "{q}")
                              .queryParam("country", "KR")
                              .queryParam("maxResults", 20)
                              .queryParam("key", "{key}")
                              .build(q, props.apiKey()))
                      .retrieve().body(byte[].class);
              r = JSON.readValue(body, GoogleBooksResponse.class);
          } catch (RestClientException | JacksonException e) {
              coolDownUntil = clock.instant().plus(props.coolDown());
              // e.getMessage()에는 key가 든 URL이 있다 — 클래스 이름만 남기고 cause도 붙이지 않는다
              throw new ProviderUnavailableException(Provider.GOOGLE_BOOKS, "호출 실패: " + e.getClass().getSimpleName());
          }
          List<EbookCandidate> out = new ArrayList<>();
          if (r.items() == null) {
              return out;
          }
          for (GoogleBooksResponse.Item it : r.items()) {
              GoogleBooksResponse.VolumeInfo v = it.volumeInfo();
              GoogleBooksResponse.SaleInfo s = it.saleInfo();
              if (v == null || v.title() == null) {
                  continue;
              }
              GoogleBooksResponse.Price p = s == null ? null : s.retailPrice();
              out.add(new EbookCandidate(it.id(), v.title(), v.authors(), v.language(),
                      s != null && Boolean.TRUE.equals(s.isEbook()),
                      p == null || p.amount() == null ? null : p.amount().intValue(),
                      p == null ? null : p.currencyCode(),
                      isbn13(v.industryIdentifiers()),
                      v.infoLink()));
          }
          return out;
      }

      private static String isbn13(List<GoogleBooksResponse.Identifier> ids) {
          if (ids == null) {
              return null;
          }
          return ids.stream().filter(i -> "ISBN_13".equals(i.type())).map(GoogleBooksResponse.Identifier::identifier)
                  .findFirst().orElse(null);
      }

      /** 괄호와 그 안을 뗀다 — "(특별판)"까지 넣으면 Google이 같은 책을 놓친다. StoreLinks와 같은 규칙 */
      private static String searchTitle(String title) {
          return title.replaceAll("\\s*[(\\[][^)\\]]*[)\\]]", "").strip();
      }

      private static String firstAuthor(String author) {
          return author.split(",")[0].strip();
      }
  }
  ```

  ```java
      public EbookWriter(JdbcClient jdbc) {
          this.jdbc = jdbc;
      }

      public Optional<EbookView> findFresh(Isbn13 isbn, Instant notBefore) {
          return jdbc.sql("SELECT matched, price, link, fetched_at FROM ebook_offer WHERE isbn13 = :i AND fetched_at > :t")
                  .param("i", isbn.value()).param("t", Timestamp.from(notBefore))
                  .query((rs, n) -> {
                      Instant at = rs.getTimestamp("fetched_at").toInstant();
                      return rs.getBoolean("matched")
                              ? EbookView.matched(rs.getInt("price"), rs.getString("link"), at)
                              : EbookView.noMatch(at);
                  })
                  .optional();
      }

      /** 한 문장(upsert)이라 트랜잭션이 따로 필요 없다 */
      public void save(Isbn13 isbn, EbookMatcher.Result result, Instant now) {
          EbookCandidate offer = result instanceof EbookMatcher.Matched m ? m.offer() : null;
          jdbc.sql("""
                  INSERT INTO ebook_offer (isbn13, matched, price, link, fetched_at) VALUES (:i, :m, :p, :l, :now)
                  ON CONFLICT (isbn13) DO UPDATE SET
                      matched = EXCLUDED.matched, price = EXCLUDED.price, link = EXCLUDED.link, fetched_at = EXCLUDED.fetched_at
                  """)
                  .param("i", isbn.value())
                  .param("m", offer != null)
                  .param("p", offer == null ? null : offer.retailPrice())
                  .param("l", offer == null ? null : offer.link())
                  .param("now", Timestamp.from(now))
                  .update();
      }
  }
  ```

  ```java
      public EbookService(BookLookupService books, EbookPricing pricing, EbookWriter writer, Clock clock) {
          this.books = books;
          this.pricing = pricing;
          this.writer = writer;
          this.clock = clock;
      }

      public EbookView offer(String rawIsbn) {
          Isbn13 isbn = Isbn13.parse(rawIsbn);
          BookView book = books.findLocal(isbn).orElseThrow(() -> new NotFoundException("책 " + isbn.value()));
          Optional<String> language = isbn.languageHint();
          if (language.isEmpty() || book.title() == null || book.author() == null) {
              return EbookView.noMatch(null);   // 어차피 가격을 표시하지 않는다 — 부르지 않는다(설계 2-1 조건 1)
          }
          Instant now = clock.instant();
          Optional<EbookView> cached = writer.findFresh(isbn, now.minus(TTL));
          if (cached.isPresent()) {
              return cached.get();
          }
          try {
              EbookMatcher.Result result = EbookMatcher.match(book.title(), book.author(), language.get(),
                      pricing.candidates(book.title(), book.author(), CallPurpose.INTERACTIVE));
              writer.save(isbn, result, now);
              return switch (result) {
                  case EbookMatcher.Matched m -> EbookView.matched(m.offer().retailPrice(), m.offer().link(), now);
                  case EbookMatcher.NoMatch n -> {
                      log.debug("전자책 같은 책 없음 isbn={} reason={}", isbn.value(), n.reason());
                      yield EbookView.noMatch(now);
                  }
              };
          } catch (ProviderUnavailableException | UserQuotaExceededException e) {
              log.info("전자책 확인 불가 isbn={} reason={}", isbn.value(), e.getMessage());
              return EbookView.unknown();
          }
      }
  }
  ```

### Task 4: 앱 골격과 API 계층 — refresh는 한 번에 하나만

`app/`에 Flutter 프로젝트를 만들고, 화면이 쓸 API 계층을 먼저 짓는다. 화면은 `BookShelfApi` 인터페이스만 알고, 테스트는 가짜 구현으로 갈아 끼운다.

인증 인터셉터가 이 Task의 핵심이다(Review Focus 1). 책 상세는 칸 네 개를 한꺼번에 부른다. access 토큰이 만료된 순간 네 요청이 모두 401을 받고, 각자 refresh를 보내면 서버는 두 번째 refresh를 **재사용(도난)**으로 보고 그 회원의 refresh를 전부 폐기한다(Phase 2 Task 3). dio의 `QueuedInterceptor`는 `onError`를 하나씩 차례로 처리한다 — 첫 요청이 refresh하는 동안 나머지는 기다렸다가, 보낸 토큰이 이미 바뀐 것을 보고 refresh 없이 새 토큰으로 다시 보낸다.

다시 보내는 요청은 **인터셉터가 없는 별도 Dio**로 보낸다. 같은 Dio로 보내면 그 요청이 다시 401일 때 `onError` 대기열이 지금 처리 중인 자기 자신을 기다려 멈춘다.

  ```dart
  class Tokens {
    const Tokens({required this.access, required this.refresh});
    final String access;
    final String refresh;

    @override
    String toString() => 'Tokens(***)';
  }

  abstract interface class TokenStore {
    Future<Tokens?> read();
    Future<void> write(Tokens tokens);
    Future<void> clear();
  }

  /// iOS Keychain (설계 7-1). 앱을 지워도 Keychain은 남을 수 있다 — 첫 실행에 남은 토큰은 그대로 쓴다(서버가 판정한다)
  class SecureTokenStore implements TokenStore {
    SecureTokenStore([FlutterSecureStorage? storage]) : _storage = storage ?? const FlutterSecureStorage();

    final FlutterSecureStorage _storage;
    static const _access = 'access_token';
    static const _refresh = 'refresh_token';

    @override
    Future<Tokens?> read() async {
      final a = await _storage.read(key: _access);
      final r = await _storage.read(key: _refresh);
      return a == null || r == null ? null : Tokens(access: a, refresh: r);
    }

    @override
    Future<void> write(Tokens tokens) async {
      await _storage.write(key: _access, value: tokens.access);
      await _storage.write(key: _refresh, value: tokens.refresh);
    }

    @override
    Future<void> clear() async {
      await _storage.delete(key: _access);
      await _storage.delete(key: _refresh);
    }
  }

  class MemoryTokenStore implements TokenStore {
    MemoryTokenStore([this._tokens]);
    Tokens? _tokens;

    @override
    Future<Tokens?> read() async => _tokens;

    @override
    Future<void> write(Tokens tokens) async => _tokens = tokens;

    @override
    Future<void> clear() async => _tokens = null;
  }
  ```

  ```dart
  import 'package:dio/dio.dart';

  import 'token_store.dart';

  /// access 토큰을 붙이고, 401이면 refresh를 한 번만 보낸 뒤 다시 보낸다.
  ///
  /// QueuedInterceptor는 onError를 하나씩 차례로 처리한다. 첫 401이 refresh하는 동안 나머지는 기다린다.
  /// 기다린 요청은 "보낸 토큰 ≠ 지금 토큰"을 보고 refresh 없이 새 토큰으로 다시 보낸다 — 서버는 이미 쓴 refresh가
  /// 다시 오면 도난으로 보고 전부 폐기하므로(Phase 2) refresh가 겹치면 정상 사용자가 로그아웃된다.
  ///
  /// refresh와 재전송은 이 인터셉터가 없는 [plain]으로 보낸다. 같은 Dio로 보내면 재전송이 다시 401일 때
  /// onError 대기열이 지금 처리 중인 자기 자신을 기다려 멈춘다.
  class AuthInterceptor extends QueuedInterceptor {
    AuthInterceptor({required this.store, required this.plain, required this.onSignedOut});

    final TokenStore store;
    final Dio plain;
    final void Function() onSignedOut;

    static const _retried = 'auth.retried';

    static bool _isAuthPath(RequestOptions o) => o.path.startsWith('/api/auth/');

    @override
    Future<void> onRequest(RequestOptions options, RequestInterceptorHandler handler) async {
      if (!_isAuthPath(options)) {
        final tokens = await store.read();
        if (tokens != null) {
          options.headers['Authorization'] = 'Bearer ${tokens.access}';
        }
      }
      handler.next(options);
    }

    @override
    Future<void> onError(DioException err, ErrorInterceptorHandler handler) async {
      final o = err.requestOptions;
      if (err.response?.statusCode != 401 || _isAuthPath(o) || o.extra[_retried] == true) {
        return handler.next(err);
      }
      final current = await store.read();
      if (current == null) {
        onSignedOut();
        return handler.next(err);
      }
      var fresh = current;
      if (o.headers['Authorization'] == 'Bearer ${current.access}') {
        // 아직 아무도 refresh하지 않았다 — 내가 한다
        try {
          final r = await plain.post<Map<String, dynamic>>('/api/auth/refresh', data: {'refreshToken': current.refresh});
          fresh = Tokens(access: r.data!['accessToken'] as String, refresh: r.data!['refreshToken'] as String);
          await store.write(fresh);
        } on DioException {
          await store.clear();
          onSignedOut();
          return handler.next(err);
        }
      }
      o.headers['Authorization'] = 'Bearer ${fresh.access}';
      o.extra[_retried] = true;
      try {
        handler.resolve(await plain.fetch<dynamic>(o));
      } on DioException catch (e) {
        handler.next(e);
      }
    }
  }
  ```

  ```dart
  import 'package:flutter_riverpod/flutter_riverpod.dart';

  import '../api/api_error.dart';
  import '../api/providers.dart';
  import '../api/token_store.dart';

  enum AuthStatus { unknown, signedIn, signedOut }

  /// 서버 Member.SLUG와 같은 규칙 — 서버에 보내기 전에 막는다
  final slugPattern = RegExp(r'^[a-z0-9][a-z0-9-]{1,28}[a-z0-9]$');

  class AuthController extends Notifier<AuthStatus> {
    @override
    AuthStatus build() {
      Future.microtask(_restore);
      return AuthStatus.unknown;
    }

    Future<void> _restore() async {
      final tokens = await ref.read(tokenStoreProvider).read();
      state = tokens == null ? AuthStatus.signedOut : AuthStatus.signedIn;
    }

    /// 로컬 전용 개발 로그인(서버가 DEV_LOGIN_ENABLED=true일 때만 열린다)
    Future<void> devLogin(String slug) async {
      final tokens = await ref.read(apiProvider).devLogin(slug);
      await ref.read(tokenStoreProvider).write(Tokens(access: tokens.accessToken, refresh: tokens.refreshToken));
      state = AuthStatus.signedIn;
    }

    /// 서버에 알리지 못해도(오프라인) 기기에서는 로그아웃한다 — refresh는 14일 뒤 서버에서 만료된다
    Future<void> logout() async {
      final store = ref.read(tokenStoreProvider);
      final tokens = await store.read();
      if (tokens != null) {
        try {
          await ref.read(apiProvider).logout(tokens.refresh);
        } on ApiException {
          // 무시한다
        }
      }
      await store.clear();
      state = AuthStatus.signedOut;
    }

    void signedOutByServer() => state = AuthStatus.signedOut;
  }

  final authProvider = NotifierProvider<AuthController, AuthStatus>(AuthController.new);

  /// 인터셉터가 "refresh까지 거부됐다"고 알리면 인증 상태를 바꾼다. main과 테스트가 같이 쓴다
  Override signedOutWiring() =>
      signedOutCallbackProvider.overrideWith((ref) => () => ref.read(authProvider.notifier).signedOutByServer());
  ```

  ```dart
  import 'package:flutter/foundation.dart';
  import 'package:flutter/material.dart';
  import 'package:flutter_riverpod/flutter_riverpod.dart';
  import 'package:go_router/go_router.dart';

  import 'auth/auth_controller.dart';
  import 'auth/login_screen.dart';
  import 'shelf/shelf_screen.dart';

  /// 테스트가 특정 화면에서 시작할 때 덮는다
  final initialLocationProvider = Provider<String>((ref) => '/');

  /// 화면 목록. 뒤 Task가 여기에 더한다
  final List<RouteBase> appRoutes = [
    GoRoute(path: '/splash', builder: (_, __) => const Scaffold(body: Center(child: CircularProgressIndicator()))),
    GoRoute(path: '/login', builder: (_, __) => const LoginScreen()),
    GoRoute(path: '/', builder: (_, __) => const ShelfScreen()),
  ];

  final routerProvider = Provider<GoRouter>((ref) {
    final auth = ValueNotifier<AuthStatus>(ref.read(authProvider));
    ref.listen<AuthStatus>(authProvider, (_, next) => auth.value = next);
    ref.onDispose(auth.dispose);
    return GoRouter(
      initialLocation: ref.read(initialLocationProvider),
      refreshListenable: auth,
      redirect: (context, state) => _redirect(auth, state.matchedLocation, ref.read(initialLocationProvider)),
      routes: appRoutes,
    );
  });

  String? _redirect(ValueListenable<AuthStatus> auth, String location, String initial) {
    switch (auth.value) {
      case AuthStatus.unknown:
        return location == '/splash' ? null : '/splash';
      case AuthStatus.signedOut:
        return location == '/login' ? null : '/login';
      case AuthStatus.signedIn:
        if (location == '/login') {
          return '/';
        }
        if (location == '/splash') {
          return initial; // 토큰을 확인하는 동안 기다리던 화면으로
        }
        return null;
    }
  }

  class BookShelfApp extends ConsumerWidget {
    const BookShelfApp({super.key});

    @override
    Widget build(BuildContext context, WidgetRef ref) {
      return MaterialApp.router(
        title: '책장',
        theme: ThemeData(colorSchemeSeed: Colors.brown, useMaterial3: true),
        routerConfig: ref.watch(routerProvider),
      );
    }
  }
  ```

  ```dart
  class LoginScreen extends ConsumerStatefulWidget {

    @override
    ConsumerState<LoginScreen> createState() => _LoginScreenState();

  class _LoginScreenState extends ConsumerState<LoginScreen> {
    final _slug = TextEditingController();
    String? _error;
    bool _busy = false;

    @override
    void dispose() {
      _slug.dispose();
      super.dispose();
    }

    Future<void> _login() async {
      final slug = _slug.text.trim();
      if (!slugPattern.hasMatch(slug)) {
        setState(() => _error = '소문자·숫자·하이픈 3~30자로 적어 주세요');
        return;
      }
      setState(() {
        _error = null;
        _busy = true;
      });
      try {
        await ref.read(authProvider.notifier).devLogin(slug);
      } on ApiException catch (e) {
        setState(() => _error = e.code == 'NETWORK' ? e.message : '로그인하지 못했어요 (${e.message})');
      } finally {
        if (mounted) {
          setState(() => _busy = false);
        }
      }
    }

      return Scaffold(
        body: SafeArea(

            padding: const EdgeInsets.all(24),
  ```

### Task 6: 기록 편집 — 한줄평은 서버와 같은 기준으로 센다

설계 4장 "기록과 편집 — 상태, 별점, 한줄평, 공개 여부". 서재나 책 상세에서 기록을 눌러 고친다. 저장은 `PUT /api/records/{id}` — **전체를 바꾼다**(별점을 지우면 null을 보낸다).

한줄평 길이(Review Focus 4): 서버는 **코드포인트 200개**까지 받는다(`ReadingRecord.REVIEW_MAX`, 앞뒤 공백을 뗀 뒤). Flutter `TextField(maxLength:)`는 **그래핌**(사람이 보는 글자)을 센다. 가족 이모지 "👨‍👩‍👧"는 그래핌 1개, 코드포인트 5개다. `maxLength`로 막으면 41개를 쓸 수 있고 서버는 400을 낸다. 그래서 `maxLength`를 쓰지 않고 코드포인트로 세서 저장 버튼을 막는다.

  ```dart
  /// 서버 한줄평 한도(ReadingRecord.REVIEW_MAX). 서버는 앞뒤 공백을 떼고 코드포인트를 센다
  const int reviewMax = 200;

  /// Flutter의 글자 수(그래핌)가 아니라 서버와 같은 코드포인트 수다. "👨‍👩‍👧"는 5다
  int reviewLength(String text) => text.trim().runes.length;

  /// 날짜는 yyyy-MM-dd 문자열이라 사전순 비교가 곧 날짜 비교다
  String? validateReadDates(String? startedAt, String? finishedAt) {
    if (startedAt != null && finishedAt != null && finishedAt.compareTo(startedAt) < 0) {
      return '다 읽은 날이 시작한 날보다 앞이에요';
    }
    return null;
  }
  ```

  ```dart
  final _isbn13 = RegExp(r'^97[89]\d{10}$');

  /// 책 바코드(EAN-13 중 978·979, 체크섬 일치)인가. 서버도 다시 검사한다 — 여기서는 서버를 부르지 않으려고 본다
  bool isBookIsbn13(String? raw) {
    if (raw == null || !_isbn13.hasMatch(raw)) {
      return false;
    }
    var sum = 0;
    for (var i = 0; i < 12; i++) {
      sum += int.parse(raw[i]) * (i.isEven ? 1 : 3);
    }
    return (10 - sum % 10) % 10 == int.parse(raw[12]);
  }

  sealed class ScanDecision {
    const ScanDecision();
  }

  class OpenBook extends ScanDecision {
    const OpenBook(this.isbn);
    final String isbn;
  }

  class NotABook extends ScanDecision {
    const NotABook(this.raw);
    final String raw;
  }

  class IgnoreScan extends ScanDecision {
    const IgnoreScan();
  }

  /// 카메라는 같은 바코드를 1초에 여러 번 읽는다. 상세는 한 번만 열고, 책이 아닌 것은 바코드마다 한 번만 알린다
  class ScanGate {
    bool _opened = false;
    String? _lastRejected;

    ScanDecision decide(String? raw) {
      if (_opened || raw == null) {
        return const IgnoreScan();
      }
      if (isBookIsbn13(raw)) {
        _opened = true;
        return OpenBook(raw);
      }
      if (raw == _lastRejected) {
        return const IgnoreScan();
      }
      _lastRejected = raw;
      return NotABook(raw);
    }
  }
  ```

  ```dart
    }
    return switch (sale.status) {
      SaleStatus.onSale => '판매 중',
      SaleStatus.order => '주문 후 발송',
      SaleStatus.unknown || null => '판매 정보 없음',
    };

  /// 설계 2-1 표시 규칙 5: 가격이 없으면 숫자를 쓰지 않는다. 서버가 이미 0·-1을 null로 바꾸지만 한 번 더 막는다
  String? priceLabel(int? won) {
    if (won == null || won <= 0) {
      return null;
    }
    final digits = won.toString();
    final out = StringBuffer();
    for (var i = 0; i < digits.length; i++) {
      if (i > 0 && (digits.length - i) % 3 == 0) {
        out.write(',');
      }
      out.write(digits[i]);
    }
    return '$out원';
  }
  ```

  ```dart
  import 'package:flutter_riverpod/flutter_riverpod.dart';

  import '../api/api_error.dart';
  import '../api/models.dart';
  import '../api/providers.dart';

  final _jamoOnly = RegExp(r'^[ㄱ-ㆎ\s]+$');

  /// 서버 QueryNormalizer와 같은 규칙(2글자 이상, 자모만은 안 됨) — 400을 받으러 가지 않는다
  bool isSearchable(String query) {
    final q = query.trim();
    return q.runes.length >= 2 && !_jamoOnly.hasMatch(q);
  }

  /// 서버는 1~10쪽만 준다(SearchService.MAX_PAGE)
  const int maxSearchPage = 10;

  class SearchState {
    const SearchState({
      this.query = '',
      this.items = const [],
      this.isEnd = true,
      this.loading = false,
      this.error,
      this.page = 0,
    });

    final String query;
    final List<SearchItem> items;
    final bool isEnd;
    final bool loading;
    final String? error;
    final int page;

    SearchState copyWith({bool? loading, String? error}) =>
        SearchState(query: query, items: items, isEnd: isEnd, loading: loading ?? this.loading, error: error, page: page);
  }

  class SearchNotifier extends Notifier<SearchState> {
    /// 검색어가 바뀔 때마다 올린다. 응답이 왔을 때 번호가 다르면 옛 검색어의 응답이다 — 버린다
    int _generation = 0;

    @override
    SearchState build() => const SearchState();

    Future<void> search(String raw) async {
      final q = raw.trim();
      final generation = ++_generation;
      if (!isSearchable(q)) {
        state = SearchState(query: q);
        return;
      }
      state = SearchState(query: q, isEnd: false, loading: true);
      await _fetch(generation, q, 1, const []);
    }

    Future<void> loadMore() async {
      if (state.loading || state.isEnd || state.items.isEmpty) {
        return;
      }
      state = state.copyWith(loading: true);
      await _fetch(_generation, state.query, state.page + 1, state.items);
    }

    Future<void> _fetch(int generation, String q, int page, List<SearchItem> before) async {
      try {
        final r = await ref.read(apiProvider).search(q, page);
        if (generation != _generation) {
          return;
        }
        state = SearchState(
            query: q, items: [...before, ...r.items], isEnd: r.isEnd || page >= maxSearchPage, page: page);
      } on ApiException catch (e) {
        if (generation != _generation) {
          return;
        }
        state = SearchState(query: q, items: before, isEnd: true, error: e.message, page: page - 1);
      }
    }
  }

  final searchProvider = NotifierProvider.autoDispose<SearchNotifier, SearchState>(SearchNotifier.new);
  ```

  ```dart
  import 'package:flutter_riverpod/flutter_riverpod.dart';

  import '../api/api_error.dart';
  import '../api/models.dart';
  import '../api/providers.dart';

  /// "N시간 전 기준"의 지금. 테스트가 고정한다
  final nowProvider = Provider<DateTime Function()>((ref) => DateTime.now);

  /// 서버에 없는 책이면 null — 화면은 "책 정보를 찾지 못했어요"와 ISBN 기록 버튼을 보여준다
  final bookDetailProvider = FutureProvider.autoDispose.family<BookDetail?, String>((ref, isbn) async {
    try {
      return await ref.watch(apiProvider).book(isbn);
    } on ApiException catch (e) {
      if (e.notFound) {
        return null;
      }
      rethrow;
    }
  });

  /// 서버는 아는 책에만 링크를 만든다(제목·저자가 있어야 전자책 서점 링크가 된다) — 책 정보를 먼저 기다린다
  final linksProvider = FutureProvider.autoDispose.family<StoreLinks?, String>((ref, isbn) async {
    final detail = await ref.watch(bookDetailProvider(isbn).future);
    return detail == null ? null : ref.watch(apiProvider).links(isbn);
  });

  /// 책 정보와 동시에 부른다 — 도서관은 ISBN만 있으면 된다
  final holdingsProvider =
      FutureProvider.autoDispose.family<List<Holding>, String>((ref, isbn) => ref.watch(apiProvider).holdings(isbn));

  final ebookProvider = FutureProvider.autoDispose.family<Ebook?, String>((ref, isbn) async {
    final detail = await ref.watch(bookDetailProvider(isbn).future);
    return detail == null ? null : ref.watch(apiProvider).ebook(isbn);
  });
  ```

### Task 9: 내 도서관 등록 — 세 곳, 하루 세 번

  ```dart
  import 'package:flutter/material.dart';
  import 'package:flutter_riverpod/flutter_riverpod.dart';
  import 'package:go_router/go_router.dart';

  import '../api/api_error.dart';

  import '../book/book_providers.dart';
  import 'library_providers.dart';

  class LibrariesScreen extends ConsumerStatefulWidget {
    const LibrariesScreen({super.key});

    @override
    ConsumerState<LibrariesScreen> createState() => _LibrariesScreenState();
  }

  class _LibrariesScreenState extends ConsumerState<LibrariesScreen> {
    List<Library>? _selected; // null이면 아직 서버의 내 도서관을 받지 않았다
    int? _region;
    String _query = '';
    bool _saving = false;

    void _toggle(Library lib) {
      final selected = [...?_selected];
      final at = selected.indexWhere((l) => l.libCode == lib.libCode);
      if (at >= 0) {
        selected.removeAt(at);
      } else if (selected.length >= maxLibraries) {
        ScaffoldMessenger.of(context)
          ..hideCurrentSnackBar()
          ..showSnackBar(const SnackBar(content: Text('도서관은 3곳까지 등록할 수 있어요')));
        return;
      } else {
        selected.add(lib);
      }
      setState(() => _selected = selected);
    }

    Future<void> _save() async {
      setState(() => _saving = true);
      try {
        await ref.read(apiProvider).setMyLibraries([for (final l in _selected ?? const <Library>[]) l.libCode]);
        ref.invalidate(myLibrariesProvider);
        ref.invalidate(holdingsProvider); // 도서관이 바뀌었다 — 빌리기 칸을 새로 조회하게
        if (mounted) {
          ScaffoldMessenger.of(context).showSnackBar(const SnackBar(content: Text('저장했어요')));
  ```

### Task 11: 공유 흐름 — 공유를 누르는 순간 공개를 묻는다

설계 7-4의 흐름 그대로:

```
공유하기 탭
   ↓ (서재가 닫혀 있으면)
"이 서재는 지금 비공개예요. 링크를 열려면 공개해야 합니다."
```

  ```dart
          actions: [

            TextButton(onPressed: () => Navigator.pop(c, RecordVisibility.ratingOnly), child: const Text('별점만 공개')),
  ```

### Task 12: iPhone 실기기에서 완료 기준 확인 — 서점에서 찍고, 집에서 공유한다

설계 4장 완료 기준을 **실제 폰으로** 확인한다: *"서점에 서서 폰으로 책을 찍으면 동네 도서관에 있는지와 어디서 살 수 있는지가 보이고, 집에 와서 그 서재 링크를 카톡으로 보낼 수 있다."*

로컬 우선이므로 서버는 맥에서 돈다. 폰과 맥이 **같은 Wi-Fi**에 있어야 한다(서점에서 찍는 것은 집에서 책장의 책으로 대신한다 — 서버가 인터넷에 없다).

폰에서 공유 링크를 열려면 서버의 `SITE_URL`이 맥의 LAN 주소(`http://192.168.x.x:8080`)여야 한다. 그런데 개발 로그인(Phase 2 이후 추가)은 `SITE_URL`이 `localhost`·`127.0.0.1`이 아니면 기동을 막는다. **사설 IP 대역(10/8, 172.16/12, 192.168/16)을 로컬로 인정한다** — 배포 서버의 공개 주소는 이 대역에 들 수 없으므로 "켜진 채 배포되는 사고"를 막는 목적은 그대로다.

  ```java
      private static final Pattern PRIVATE_IPV4 = Pattern.compile(
              "^(10\\.\\d{1,3}|172\\.(1[6-9]|2\\d|3[01])|192\\.168)\\.\\d{1,3}\\.\\d{1,3}$");

      /**
       * localhost·127.0.0.1과 사설 IPv4(10/8, 172.16/12, 192.168/16)만 로컬로 본다 — 폰에서 공유 링크를 열려면
       * SITE_URL이 맥의 LAN 주소여야 한다. 배포 서버의 공개 주소는 이 대역에 들 수 없다.
       */
      static void requireLocal(String siteUrl) {
          String host = siteUrl == null ? null : URI.create(siteUrl).getHost();
          if (host == null || !(LOCAL_HOSTS.contains(host) || PRIVATE_IPV4.matcher(host).matches())) {
              throw new IllegalStateException("개발 로그인은 로컬에서만 켤 수 있다 — SITE_URL=" + siteUrl);
          }
      }
  ```
