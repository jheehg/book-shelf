# 외부 제공자 실측 기록

제공자를 넣거나 바꿀 때는 **실측 결과를 여기에 남긴다** (설계 문서 6장).
문서의 설명이 아니라 실제 응답을 기준으로 적는다.

---

## 2026-09 — 알라딘과 네이버가 닫혔다

| 제공자 | 상태 | 근거 |
|---|---|---|
| 알라딘 OpenAPI | 신규 신청 중단(9월), 기존 이용자는 **2026-10-30까지** | [알라딘 공지](https://blog.aladin.co.kr/cscenter/17483675) |
| 네이버 책 검색 / 쇼핑 검색 | **2026-07-31 완전 종료, 대체 없음.** NAVER API HUB로 이관된 것은 블로그·지역 등이고 책·쇼핑은 빠졌다 | [이관 안내](https://waffleboard.io/blog/naver-search-api-hub-migration-guide), 개발자센터 앱 등록 드롭다운에 "검색"이 없음을 직접 확인 |

같은 여름에 두 곳이 모두 닫혔다. **상업 서점·포털의 책 데이터 API는 닫히는 추세로 본다.**
그래서 기반은 공공 데이터(정보나루)에 두고, 상업 API는 없어져도 되는 보강으로 둔다.

알라딘 상품 페이지 스크래핑은 검토 후 배제했다 — 공식 API를 닫은 뒤의 자동 수집은 약관 위반이고,
HTML이 바뀌면 조용히 틀리며, 서버 IP 하나가 막히면 전원이 막힌다.

## 카카오 책 검색 (`GET https://dapi.kakao.com/v3/search/book`) — 2026-09-27

인증: `Authorization: KakaoAK {REST API 키}`. 호출 22회.

| 항목 | 결과 |
|---|---|
| 수록률 | 11/11. 국내 신간·스테디·구간·번역서·해외 원서(Atomic Habits 영국판)까지 |
| ISBN 조회 | `target=isbn`. 13자리·10자리 모두 된다. 없는 ISBN은 `total_count: 0` (오류 아님) |
| 표지 | `thumbnail` — 샘플 전부 있음 |
| 가격 | `price`(정가), `sale_price`(판매가). **`sale_price = -1` 또는 `price = 0`이면 가격 없음** (487건 중 154건) |
| 판매 상태 | `status` 값은 세 가지뿐: `정상판매` 360, `주문판매` 3, **빈 문자열** 124(주로 오래된 책). "품절"·"절판" 값은 관측되지 않았다 → 빈 값을 절판으로 단정하지 않는다 |
| ISBN 형식 | `"8936434128 9788936434120"` 공백 구분. 13자리 하나만 오는 경우 113건, 앞에 공백이 붙는 경우도 있다 |
| 쪽수 | **필드 없음** |
| 링크 | `url`은 다음 검색의 책 페이지(서점 아님) |
| 응답 시간 | 55~204ms |
| 한도 | Daum 검색 합산 **일 30,000 / 월 3,000,000** ([카카오 문서](http://developers.kakao.com/docs/ko/getting-started/quota)). 응답 헤더에 남은 한도 정보는 없다 |

## Google Books (`GET https://www.googleapis.com/books/v1/volumes`) — 2026-09-30

`key=...&country=KR`. 호출 18회. 종이책 ISBN 조회와 `intitle:… inauthor:…` 조회를 둘 다 했다.

| 책 | 제목+저자로 찾은 판매 중 전자책 | 판정 |
|---|---|---|
| 소년이 온다 | 소년이 온다 10,800원 | 맞음 |
| 채식주의자 | 채식주의자(개정판) 12,240원 | 맞음 (다른 판) |
| 아주 작은 습관의 힘 | 같은 책(50만 부 기념판) 11,340원 | 맞음 |
| 토지 1권 | 7·14·18권만 | 1권 못 찾음 |
| 세이노의 가르침 | 0원 | 불분명 — 가격 표시하지 않는다 |
| 불편한 편의점 | 중국어판 《不便利的便利店2》 | **오탐** |
| Atomic Habits | 타밀어판 | **오탐** |
| 아몬드, 해리 포터 | 없음 | — |

- **종이책 ISBN으로는 전자책이 안 나온다.** 9권 모두 종이책 항목만, 전부 `NOT_FOR_SALE`, 표지 대부분 없음
- 제목+저자 검색은 오탐이 섞인다 → **같은 책 확인**(설계 문서 2-1) 없이는 보여주지 않는다
- 응답 시간 0.5~1.7초 (카카오의 약 10배)
- 한도: 문서에 없다. Cloud 콘솔 → Books API → 할당량에서 확인 필요 (**미확인**)
- 조건 ([약관](https://developers.google.com/books/terms), [브랜딩](https://developers.google.com/books/branding), [사용 가이드](https://developers.google.com/books/docs/v1/using)):
  - 앱 사용에 요금을 받으면 안 된다(별도 계약 없이는)
  - 결과 옆에 "powered by Google", 각 결과에 Google Books 페이지 링크
  - 결과가 요청 서버의 IP 위치에 따라 달라진다 → 도쿄 서버에서 `country=KR`로 원화 가격이 나오는지 배포 때 확인

## 도서관 정보나루 (`http://data4library.kr/api/*`) — 2026-10 실측

`authKey=...&format=json`. 호출 약 20회.

| 확인 항목 (설계 6-7) | 결과 |
|---|---|
| 도서관별 소장·대출 (`bookExist?libCode&isbn13`) | `{"hasBook":"Y|N","loanAvailable":"Y|N"}` — **대출 가능(Y,Y) / 대출 중(Y,N) / 미소장(N,N)** 세 상태로 옮길 수 있다. 모르는 ISBN도 오류 없이 (N,N) |
| 갱신 주기 | **"조회일 기준 전날 대출상태"** ([정보나루 공지 2020-07-27](https://data4library.kr/noticeV?cn=129)). 설계의 (가정) "전날 기준"이 맞다 → 캐시는 기준일 다음 날 00:00 KST까지 |
| 지역으로 도서관 찾기 (`libSrch?region`) | 된다. 서울(region=11) 359곳. `libCode, libName, address, tel, latitude, longitude, homepage, operatingTime, closed, BookCount` |
| 책을 소장한 도서관 (`libSrchByBook?isbn&region`) | 된다. 소년이 온다 서울 321곳 |
| 쪽수 | **없다.** `srchDtlList`에 쪽수 필드가 없다 → 설계의 (가정) "쪽수를 정보나루로 채운다"는 틀렸다 |
| 도서 상세 (`srchDtlList?isbn13`) | 제목(부제 포함, 예: `소년이 온다 :한강 장편소설`), 저자(`지은이: 한강` 형식), 출판사, 출판년도, 분류, 소개, 표지(`image.aladin.co.kr` 주소). 모르는 ISBN은 `errCode` 응답 |
| 도서 검색 (`srchBooks`) | `keyword=`는 **대출 건수 순**이 기본이라 "소년이 온다"에 다른 책이 먼저 나온다. **`title=`로 검색하면 맞게 나온다**(소년이 온다·Atomic Habits·아몬드 모두 첫 결과). 가격·판매 상태는 없다 → **`BookCatalog`의 대체 구현으로 쓸 만하다**(책 정보·검색만, 새 책 칸은 "확인 불가") |
| 응답 시간 | 검색 39~80ms, 도서관·소장 조회 326~649ms |
| 한도 | **공개 문서·매뉴얼(v20260620, 70쪽)·응답 헤더 어디에도 없다.** 발급 화면에서 확인 필요 |
| 약관 | 매뉴얼에 캐시·출처 표시 조건 없음. 이용약관 확인 필요 |

## 아직 확인하지 않은 것 (W1)

- 카카오 약관: 캐시 보관 기간, 출처 표시 의무, 공개 웹에 가격을 게재해도 되는지. 한도 초기화 시각
